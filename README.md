<h2>About the Project</h2>

<p>
Dentistry is a modern orthodontic practice website developed for LexHack '26. The project is designed around a fictional dental practice, <strong>Orthodontic Associates of New England</strong>, with the goal of creating a comprehensive and user-friendly digital experience.
</p>

<p>
The website brings together patient-facing pages, professional profiles, administrative interfaces, and content management features into a unified platform. It explores how modern web technologies can be used to improve the digital presence and accessibility of a dental practice.
</p>

<h2>Features</h2>

<ul>
<li><strong>Modern Landing Page:</strong> A polished homepage featuring navigation, introductory content, and visual elements.</li>
<li><strong>Doctor Profiles:</strong> Dedicated pages and sections showcasing doctors and their professional backgrounds.</li>
<li><strong>Staff Directory:</strong> An organized interface introducing practice staff members.</li>
<li><strong>New Patient Portal:</strong> A dedicated interface for prospective patients.</li>
<li><strong>Administrative Dashboard:</strong> An interface designed to represent administrative functionality.</li>
<li><strong>Doctor Portal:</strong> A dedicated portal interface for medical professionals.</li>
<li><strong>Staff Portal:</strong> An interface designed for practice staff.</li>
<li><strong>Blog Library:</strong> A dedicated section for browsing practice-related articles.</li>
<li><strong>Blog Author Portal:</strong> An interface for managing and organizing blog content.</li>
<li><strong>Smile Gallery:</strong> Before-and-after image comparisons showcasing orthodontic transformations.</li>
</ul>

<h3>Run Locally</h3>

<p>To run the project on your local machine, follow these steps:</p>

<p><strong>3. Open the website</strong></p>

<p>
Open <code>index.html</code> in your preferred web browser. Alternatively, use the Live Server extension in Visual Studio Code to launch a local development server.
